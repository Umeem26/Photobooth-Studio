# Contributing

Thanks for helping with Van de Booth. This is a small project; short, focused pull requests are easiest to review.

## Set up

Requirements: JDK 17+ (21 for packaging), Node.js 20+. Maven is not needed (the wrapper is included).

```bash
npm install
npm run dev          # Vite + Electron; Electron starts the Java sidecar
```

## Test before you push

```bash
./mvnw verify        # JUnit (headless) and the fat JAR (Windows: mvnw.cmd verify)
npm test             # Vitest and the Node tests
npm run e2e          # Playwright against a real sidecar and a fake camera
```

No test needs a webcam, printer or GUI session for Java. End-to-end tests use Chromium's fake camera; screenshots in `docs/screenshots` are regenerated by them.

## Guidelines

- One small commit per change, with a message that says what and why.
- Java engine in `src/main/java` (package per concern), UI in `ui/` (React + TypeScript), Electron shell in `desktop/`.
- UI text is English and lives in `ui/src/strings.ts`. Colors come only from the tokens in `ui/src/styles/tokens.css`; no gradients or emoji. Buttons are at least 96 px tall on the 1920x1080 canvas (72 px in Operator Mode). Read `docs/design-system.md` before changing screens.
- A new layout is one entry in `StripLayout` (canvas, cells, footer) plus its name in `strings.ts`; the tests under `StripLayout` and `e2e/layouts.spec.ts` cover the geometry and the on-screen fit.
- Dependencies come from Maven Central or npm and are managed in `pom.xml` and `package.json`. Do not commit JARs, secrets, PINs or tokens.
- Tests must stay headless and use a temporary `vandebooth.config.dir`.
